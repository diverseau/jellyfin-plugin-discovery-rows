# Evidence samples

These illustrate the schema, not factual claims about a real title. The all-zero local ID is a placeholder that must be replaced using Discovery Rows → Evidence → Find local titles.

Never import invented awards, moods or series facts. Replace sample dates, categories, episode counts and source URLs with independently checked information. A record only affects a title with that exact work key.

`facet-template.json` shows reviewed mood/structure labels. `series-template.json` illustrates an aired-order manifest and whole-story assertion. For awards, a record in `awards` requires `workKey`, `body` (`academy`, `golden_globes`, `emmy`), `ceremonyYear`, `category`, `outcome` (`nominee`/`winner`), `contribution` and a checked `evidenceUrl`. Put it under the same work's record. Use the administrator editor to preserve existing fields when adding facts.
